# 📊 Sales Data Analysis Dashboard

## 📌 Project Overview

This project presents an end-to-end sales analytics case study using the Sample Superstore dataset.

The objective is to transform raw transactional data into meaningful business insights through data cleaning, feature engineering, exploratory data analysis (EDA), and business-focused recommendations.

The analysis evaluates sales performance across different regions, states, product categories, customer segments, shipping modes, and discount levels to identify business opportunities and support data-driven decision-making.

## 💼 Business Problem

Businesses generate large volumes of transactional data every day, but raw data alone does not provide meaningful insights.

The challenge is to identify:

- Which regions generate the highest revenue?
- Which products are most profitable?
- Which products generate losses?
- How do discounts affect profitability?
- Which customer segments contribute the most?
- Which customers should be retained?
- Which states require business attention?
- Which shipping modes perform the best?

This project answers these questions using data analytics techniques.

## 🎯 Project Objectives

- Perform data quality assessment
- Apply feature engineering for time-based analysis
- Analyze business KPIs
- Identify sales trends
- Evaluate regional and state performance
- Analyze product categories and sub-categories
- Study customer segments and customer profitability
- Analyze the impact of discounts on profit
- Evaluate shipping mode performance
- Generate business insights and actionable recommendations

## 📂 Dataset Information

- **Dataset Name:** Sample Superstore
- **File Format:** Excel (.xls)
- **Records:** 9,994
- **Columns:** 21 (before feature engineering)
- **Source:** Kaggle Sample Superstore Dataset

The dataset contains transactional sales records, including customer information, product details, geographical information, shipping details, discounts, sales, and profit.

## 💡 Key Business Insights

- California generated the highest sales and profit.
- Texas generated high sales but recorded the largest loss.
- The West region was the best-performing region.
- Technology was the most profitable product category.
- Tables and Bookcases were the major loss-making sub-categories.
- Higher discounts were generally associated with lower profitability.
- The Consumer segment generated the highest sales.
- Standard Class shipping generated the highest sales and profit.
